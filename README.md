# Unique Video Generator

Desktop-приложение (Python + customtkinter) для пакетной генерации коротких видео: берёт видео на зелёном фоне, накладывает его на фоновое изображение через chromakey, добавляет текстовый оверлей (опционально сгенерированный через Gemini API) и рендерит результат через FFmpeg.

Проект писался как pet-project для практики работы с видео-пайплайнами, многопоточностью в GUI-приложениях и построением сложных FFmpeg filter graph'ов.

## Что делает

- GUI на `customtkinter`: настройка "паков" (видео + текст + аудио + громкость), пресеты стилей текста, live-превью.
- Композитинг видео: chromakey + despill для удаления зелёного фона, наложение на фоновое изображение, оверлей текста (рендерится в PIL, накладывается через FFmpeg filter_complex).
- Опциональная генерация текста через Gemini API (`google-generativeai`).
- Многопоточный рендер-пайплайн с прогресс-баром и логом, сохранение/загрузка настроек проекта в JSON.
- Скачивание фоновых изображений с Pinterest через Playwright (headless-браузер, без официального API).
- Рандомизация метаданных выходного видео (модель устройства, `creation_time` и т.д.) — экспериментальная часть, которую делал, чтобы разобраться, как ffmpeg работает с контейнерными метаданными.

## Технически интересные моменты

- Построение динамического `filter_complex` в FFmpeg (chromakey → overlay фона → overlay текста → аудио-микс) в зависимости от того, какие входы вообще заданы.
- Синхронизация фонового потока рендера с GUI через `self.after()` вместо блокировки интерфейса.
- Генерация текстового оверлея как отдельного PNG с альфа-каналом через PIL (скругление, паддинги, перенос строк) — чтобы не зависеть от `drawtext` в FFmpeg и шрифтов, доступных ffmpeg'у в системе.

## Стек

Python, customtkinter, Pillow, FFmpeg/ffprobe (через subprocess), Playwright, Gemini API (google-generativeai)

## Честно о слабых местах

- Скачивание фонов идёт скрапингом Pinterest через Playwright, а не через официальный API — рабочий вариант для личного пет-проекта, но не production-ready и не то, что стоит тащить в реальный продукт как есть.
- Рандомизация метаданных устройства — экспериментальный кусок, изучал как раз ffmpeg/контейнерные метаданные, а не готовое к продакшену решение.
- Нет тестов, GUI и бизнес-логика сильно перемешаны в одном файле — будь это не pet-project, а рабочий код, вынес бы рендер-пайплайн и работу с Pinterest в отдельные модули/сервисы.
- API-ключ Gemini можно сохранить в JSON локально (см. `.gitignore` — такие файлы специально исключены из репозитория).

## Запуск

```bash
pip install -r requirements.txt
playwright install chromium
python app.py
```

Требуется установленный FFmpeg/ffprobe в PATH.
